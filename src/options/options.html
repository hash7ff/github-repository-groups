Repository Groups for GitHub

Shows your repositories on github.com/<you>?tab=repositories in collapsible groups. The groups are stored in this browser; nothing is ever written to GitHub.

Connect the Repository Groups GitHub App. You will get a short code to enter on GitHub; no token to create or paste.

Why an app? GitHub only lets an app list your private repositories after you install it on them. The app asks for read-only access to repository metadata (names, descriptions, languages) and nothing else: it cannot read your code and cannot change anything on GitHub.

Groups live in Chrome's sync storage for this extension. With Chrome sync turned on they follow you to other computers signed in to the same Google account; with sync off they stay in this browser only. Export a copy as a backup or to move to another browser.

Delete every group in this browser, and in Chrome sync on your other computers? Your repositories are not touched. Export first if you may want them back.

Advanced

Use a personal access token instead of signing in

For people who prefer a token. A fine-grained token with Metadata: Read-only is enough; do not add other permissions (create one). Saving a token replaces the GitHub sign-in.

Stop using the extension

Nothing is left behind if you do all four. Each step is independent.

  1. Delete your groups with “Delete all groups…” above (this also clears them from Chrome sync).
  2. Sign out above: the GitHub credential is removed from this browser.
  3. Remove the app's access on GitHub: GitHub → Settings → Applications → Installed GitHub Apps → Repository Groups → Configure → Uninstall, and Authorized GitHub Apps → Repository Groups → Revoke. For an organization, its owner uninstalls it under the organization's Settings → GitHub Apps.
  4. Remove the extension from chrome://extensions.

Privacy

  • Nothing is written to GitHub. The extension only reads your repository list.
  • Your groups (group names and which repository ids are in them) are kept in Chrome's storage for this extension. They are never sent to us. With Chrome sync on, Google keeps them as part of your Chrome sync data, like bookmarks.
  • Your GitHub credential is stored in this browser profile (chrome.storage.local) and is sent only to GitHub. It is never given to the GitHub web page or written to logs.
