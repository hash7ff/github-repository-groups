Repository Groups for GitHub

Collapsible groups on your GitHub Repositories tab, GitLab-group style. Kept in your browser; nothing is written to GitHub.

Install Source on GitHub

How it works

Repositories (Grouped | Original)

▼ Platform  (3)            ← your groups, collapsible
    api
    infra
    web
▶ Mobile  (2)
▼ Ungrouped  (1)           ← everything not in a group
    meeting-notes
  • Nothing is written to GitHub. The extension only reads your repository list, through GitHub's documented REST API.
  • Groups live in your browser, in Chrome's sync storage: with Chrome sync on they follow you to your other computers, like bookmarks.
  • Built not to break. The list comes from the API rather than from GitHub's page, so a GitHub redesign does not take your groups away.
  • Always escapable. A Grouped | Original switch brings back GitHub's own list at any time, and GitHub's Find, Type, Language and Sort controls keep working.

Install

Get it from the Chrome Web Store. Then open the extension's settings, click Sign in with GitHub, enter the short code on GitHub, and install the Repository Groups app on your repositories. GitHub lets an app list private repositories only after you install it on them; the app asks for read-only repository metadata and nothing else.

To stop using it: in the settings, Delete all groups… and Sign out; on GitHub, Settings → Applications → uninstall the app and revoke its authorization; then remove the extension. Nothing is left behind.

Developers can build it from source and load it unpacked.

Privacy

No analytics, no servers of our own. Your GitHub credential stays in your browser and is sent to GitHub only. Read the privacy policy.
